# 平面点集反射性（Reflexivity）极值问题

## 题面

给 n 点集添加最少多少个点使其'自反'（每条确定线两侧点数≤3 型条件）？

### 形式化表述

求 R(n) 精确值/上界（小 n 精确，一般渐近）。

## 原文摘录

> TOPP topp-0066 (Pach–Pinchasi et al.): characterize R(n), the minimum total number of reflex points needed so that a set of n points becomes reflexive.
>
> —— 来源: TOPP topp-0066 (Pach–Pinchasi 线)

## 已知结果与进展

R(3) 等小值已知；一般开放。

## 边界与约定

- 日期: 2026-11-21；添加者: SOL验证Agent（C层抽样轨道C）；性质: 仅列检查点
- 定义边界: 自反条件的精确陈述（线两侧计数阈值——"≤3型"须精确化）；反射点是否须与原集一般位置
- 最小参数: R(2), R(3)已知小值核对；共线退化配置
- 建议独立验证: 小n（≤8）几何穷举最小反射点数（与Pach–Pinchasi结果不同源）
