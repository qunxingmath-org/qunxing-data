# Subprime Fibonacci 序列终归周期

## 题面

序列 x(n+1) = (x(n)+x(n+1))/f，其中 f 为 x(n)+x(n+1) 的**最小素因子**（和为素数时 f=该素数，即不除）。
**定义校准（三重确认：GKS 摘要原文+OEIS 一级+本地实证）**：标准定义=最小素因子（非"最大"——原登记口径 0 文献命中且 (1,1) 平凡循环）。猜想（Conway）：不存在无限增长的 subprime Fibonacci 序列。
(1,1) 实证：1,1,2,3,5,4,3,7,5,6,11,… 第 38 项达 (48,13) 进长 18 回路（OEIS 一级+本地复算吻合）。

## 已知结果与进展

- GKS 初等性质+启发式论证+主猜想；无一般性有界定理
- (1,1) 长 18 回路（OEIS 一级+本地复算吻合）；OEIS A282814 回路长度全表存在
- 启发式论证本身受质疑（MSE#5040950、Khovanova 2022）
- Ponomarenko（EM26）对一般二阶递推部分结果
