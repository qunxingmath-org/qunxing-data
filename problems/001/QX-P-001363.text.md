# 2 的幂的十进制无零数字（CRUX 410）

## 题面

2^n 的十进制表示不含数字 0 的 n 是否只有有限多个？（"86 猜想"：2^86 是最后一个。）

### 形式化表述

#{n≥1: 2^n 的十进制不含 '0'} < ∞？

## 原文摘录

> James Gary Propp，Crux Problem 410 (1978)，Rabinowitz 索引 p.417：是否只有有限多个 2 的幂其十进制表示中不含数字 0？
>
> —— Rabinowitz 索引 p.417

## 已知结果与进展

- 2^86 为已知最大无零幂（Khovanova 博客 2011；Sloane Numberphile "Problems with Powers of Two"）；启发式 (9/10)^d 衰减；底 3 类似（69..20000 无零）。无定理。
