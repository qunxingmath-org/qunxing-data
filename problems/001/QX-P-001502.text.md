# Is a bounded convex domain visible iff it has the Denjoy-Wolff property?

## 题面

有界凸域的visibility性质与Denjoy-Wolff性质（轨道收敛到单一边界点的DW型行为）是否等价？2025年构造的非可见光滑凸域（无解析圆盘）失败DW性质——支持'visible⟹DW'方向。

### 形式化表述

证明双向等价或找反例。

## 原文摘录

> Conjecture 4.9: visibility ⇔ Denjoy-Wolff property for bounded convex domains.（Bracci-Ökten清单 arXiv:2507.19967）
