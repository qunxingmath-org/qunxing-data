# 孤立数（solitary numbers）的密度是否为零

## 题面

没有"朋友"（同 I 值伙伴）的孤立数全体，其自然密度是否为 0？

### 形式化表述

d({n: I(n) 仅被 n 取得}) = 0？

## 原文摘录

> C. W. Anderson & Dean Hickerson，AMM Problem 6020 (1975)，Rabinowitz 索引 p.413：孤立数（无 friend 的数，即 abundancy index I(n)=σ(n)/n 无他人共享）的密度是否为零。
>
> —— Rabinowitz 索引 p.413

## 已知结果与进展

- 全部素数、素数幂、(σ(n),n)=1 的数为孤立；I(n)>α 的数密度恰 1/2（density map 文献）；friendly 数密度（若存在）是否为 0 亦开放（Wikipedia）。

- 日期: 2026-11-21（描述性清单，本轮不执行搜索）
- 最小参数/退化: n=1（I(1)=1——孤立 ✓）；自然密度 vs 对数密度口径（原文 natural density——注记）。
- 量词/等号分支: "I(n) 仅被 n 取得"量词；与 friendly 密度问题的互补关系（d(solitary)+d(friendly)≤1——注记）。
