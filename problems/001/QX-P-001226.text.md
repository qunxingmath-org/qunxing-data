# γ–θ猜想（永恒支配数）

## 题面

永恒支配（eternal domination）参数链中的具体间隙问题：三个参数是否可取两个相等而第三个严格更大。

### 形式化表述

∃ G: γ(G)=γ_∞(G) 且 γ_∞(G)<θ(G)。

## 原文摘录

> 是否存在图G使 γ(G)=γ_∞(G)<θ(G)（支配数=永恒支配数<全支配数?θ为特定控制参数）。
>
> —— Wikipedia: Eternal dominating set

## 已知结果与进展

参数间不等式链已知；等号情形刻画部分；构造候选开放。
