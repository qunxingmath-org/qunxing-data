# Whitney 集合 D 的补集排序公式（FQ H-271）

## 题面

给出不在 D 中的正整数按序排列后的通项公式（D 结构类比 Moser–de Bruijn）。

### 形式化表述

求 S_n = 第 n 个不属于 D 的正整数的显式公式/算法。

## 原文摘录

> R. Whitney，Fibonacci Quarterly H-271 (1979)，Rabinowitz 索引 p.418：D = {∏(a_i+2^i): a_i∈{0,1}}；D 的补集排序后第 n 项 S_n 的公式。
>
