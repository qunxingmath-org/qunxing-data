# Do all staged tree models have toric structure?

## 题面

staged tree模型（离散统计模型，有根有向树+同色节点条件概率相同）的理想是否均为toric理想？原文识别出具有toric理想的类并研究其代数几何，全类判定开放。

### 形式化表述

对每个staged tree T，判定其模型理想 I_T ⊂ K[p_e] 是否为toric理想（素理想+参数化生成）。已知若干类toric（原文+后续'不toric的Bayesian网络'文献有反例类）。

## 原文摘录

> It is an open problem whether all staged tree models have toric structure.（Görgen-Maraj-Nicklasson, arXiv:2107.04516 摘要）
>
> —— arXiv 预印本（发表版 JSC 2022）

## 已知结果与进展

原文（J. Symbolic Computation 113 (2022) 242-268发表版）刻画toric staged trees类；'Toric and Non-toric Bayesian Networks'第5节列开放问题；MPI MathRepo页面收录实例；Drton等2023综述提及；Uppsala 2024博士论文继续该问题。
