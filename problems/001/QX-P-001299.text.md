# Is there an online learning algorithm making sublinear mistakes on every sequence whenever such an algorithm can exist?

## 题面

二分类在线学习：若点序列X（可随机）本身容许某个学习算法对该序列做到亚线性错误，是否存在单一算法对所有目标概念在该序列上保证亚线性错误？（'能学则统一可学'）

### 形式化表述

判断存在算法A使：对一切h与一切满足容学条件的X，mistakes_A(h,X)=o(T)。已知：i.i.d.情形O(log T)期望错误算法存在（Hanneke）。

## 原文摘录

> This open problem asks whether there exists an online learning algorithm for binary classification that guarantees, for all target concepts, to make a sublinear number of mistakes, under only the assumption that the (possibly random) sequence of points X allows that such a learning algorithm can exist for that sequence.（S. Hanneke, arXiv:2107.09542 摘要）
>
> —— arXiv 预印本（COLT 2021公开问题）

## 已知结果与进展

COLT 2021公开问题（PMLR v134，cited 8）；Hanneke 2025 universal multiclass/transductive系列；NeurIPS 2025 'Optimal Mistake Bounds for Transductive Online Learning'（30年transductive问题解决——相邻进展）。本条问题无解决。

## 边界与约定

- 最小参数/退化: T→∞渐近口径（亚线性=o(T)）；有限假设类（已知可学基线支）；单点序列/常数序列退化。
- 分支/等号: "容学条件"（存在某算法对该序列亚线性）本身依赖h的量词序——与主问题量词交互为本条微妙点；i.i.d.情形O(log T)已知（译述✓）。
- 独立验证建议（与查新途径不同源）: 构造对抗序列族数值测试候选统一算法（mistake计数曲线）；可数假设类特例的显式构造尝试。
