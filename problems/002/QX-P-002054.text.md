## 原文摘录

> Kolmogorov Arnold reperesentation theorem states that (the extended version by Lorentz) every multivariate continuous function $f:[0,1]^n\rightarrow \mathbb{R}$ can be written in the following form, which basically says that there is a decomposition using univariate functions:
> $$f(x_1,x_2,...,x_n) = \sum_{q=0}^{2n} \Phi\left(\sum_{p=1}^{n}\phi_{q,p}(x_p)\right)$$
> such that $\phi_{q,p}:[0,1]\rightarrow \mathbb{R}$ and $\Phi:\mathbb{R}\rightarrow\mathbb{R}$ .
