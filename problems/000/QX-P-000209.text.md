# Erdos P94: convex polygon, sum f(u_i)^2 << n^3

## 题面

凸n边形各距离出现次数f(u_i): 证明 Σf(u_i)² ≪ n³。

### 形式化表述

∀ convex n-point set X: Σ_d mult(d)² = O(n³). (平凡Σmult(d)=n(n-1)/2.)

## 已知结果与进展

- [PARTIAL] Lefmann–Thiele [LeTh95]: 无3共线情形更强结论。
- [NOTE] Fishburn解声称无出处([Er97c]), 状态存疑未确认。

## 边界与约定

- 边界：凸位置前提（含退化共线时结论平凡性）；mult(d)计无序对。
- 独立验证建议：规则多边形/随机凸位置点集数值计算Σmult²增长率。
