# 单色空三角形（原批次 A-088）

## 题面

平面一般位置 2-着色点集中，是否必存在单色"空三角形"（三点同色，且其凸包内部不含任何点）？

### 形式化表述

∀有限点集 P⊂R²（一般位置）与其 2-着色，∃{p,q,r}⊂P 同色且 conv{p,q,r}∩P = {p,q,r}。

## 原文摘录

> (OPG, 2008-10-08) If P is a finite set of points which is 2-colored, an empty triangle is a set of 3 points ... must every 2-colored point set (in general position) contain a monochromatic empty triangle?
>
> —— OPG 页

## 已知结果与进展

- 空三角形经典结果（每个大点集含空三角形，无着色版）。
- 2026-01 arXiv "On the Number of Almost Empty Monochromatic Triangles"（almost-empty 变体计数——邻域活跃）。

## 边界与约定

- 边界：一般位置（无三点共线）已含于前提；小点集（≤6点）平凡性检查。
- 独立验证建议：程序枚举着色与点构型搜索无单色空三角形的最大规模。
