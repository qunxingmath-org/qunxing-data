# Erdos P20: sunflower conjecture f(n,k) < c_k^n

## 题面

向日葵猜想: n元集族规模≥f(n,k)必含k-向日葵; f(n,k)能否≤c_k^n（固定k的指数界）?

### 形式化表述

f(n,k) ≤ c_k^n (k固定)? 已证 f(n,k) ≤ (Ck log n)^n (Rao 2020; Frankston–Kahn–Narayanan–Park 2019; Bell–Chueluecha–Warnke 2021)。

## 已知结果与进展

- [PARTIAL] ALWZ (2020)→(Ck log n log log n)^n; Rao/FKNP/BCW 2019-2021→(Ck log n)^n。
- [BACKGROUND] Kostochka (1997): o(n!)。

## 边界与约定

- 边界：k=3为最难档；向日葵核心可空。
- 独立验证建议：小n固定k穷举最大无向日葵族规模检验指数底数。

## 相关进展与声称解决

- [PARTIAL] ALWZ (2020)→(Ck log n log log n)^n; Rao/FKNP/BCW 2019-2021→(Ck log n)^n。
- [BACKGROUND] Kostochka (1997): o(n!)。
