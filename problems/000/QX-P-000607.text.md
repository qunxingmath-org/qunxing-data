# （来源 C-014）Snark 定理（每个 snark 以 Petersen 图为 minor，Robertson–Sanders–Seymour–Thomas 1999 宣布证明）现状如何？

## 题面

Snark 定理（每个 snark 以 Petersen 图为 minor，Robertson–Sanders–Seymour–Thomas 1999 宣布证明）现状如何？

补充：MSE 0 回答。核实记录：Combinatorica 2019 论文参考文献仅引用 arXiv:1403.2118（Excluded minors in cubic graphs）；后者经 OpenAlex 确认 2019 年发表于 J. Comb. Theory B 138 (2019) 219–285。故 RSS&T 的完整证明很可能已随该文发表——但 Wikipedia（MSE 提问时点）仍称 unpublished。需要对照论文内容最终确认 snark 定理是否完整包含。
> [修正注记] 2026-11-21 主控终审Agent：上行"很可能已随该文发表"推断**经全文核验证伪**——arXiv:1403.2118/JCTB 2019 全62页实取（pdftotext）**0处出现"snark"字样**，其定理1.1为theta-connected结构定理（"G does not contain Petersen ⟺ apex ∨ doublecross ∨ Starfish"），不单独覆盖snark定理。修正后表述：snark定理由已发表链条推出——RST"Tutte's edge-colouring conjecture"JCTB 70 (1997) 166-183（归约至theta-connected+apex）+ 本论文定理1.1（JCTB 138, 2019）+ Edwards–Sanders–Seymour–Thomas"Three-edge-colouring doublecross cubic graphs"JCTB 119 (2016) 66-95 + 4CT（apex情形）——**无单一已发表完整证明**；近年部分文献当定理引用（"Snark Theorem, Edwards–Robertson–Sanders–Seymour–Thomas"），Wikipedia 仍称完整证明 unpublished（两种口径并存）。详见 evidence.md 主控终审核验节。

### 形式化表述

验证性问题：RSS&T 1999 宣布的 snark 定理证明至今未见期刊发表。相关子结果已发表：Girth Six Cubic Graphs Have Petersen Minors（Robertson-Seymour-Thomas, Combinatorica 39 (2019) 519-544, arXiv:1405.0533）；大定理完整证明的论文 Excluded minors in cubic graphs（arXiv:1403.2118, 62页）已发表于 JCTB 138 (2019) 219-285（OpenAlex/Crossref 核实，DOI 10.1016/j.jctb.2019.02.002）——但该论文是否即完整 snark 定理仍待核对。问题转化为：确认 JCTB 2019 论文是否覆盖 snark 定理全部内容。
