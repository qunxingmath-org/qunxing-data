# Distributions of Mesh Patterns of Short Lengths on Separable Permutations

## 题面

证明或否定：至多124对同 shading 的 {12,21} 型 mesh pattern 在可分置换上等分布。行动目标：完成剩余14类（38-24）分布的显式确定，从而把猜想化为有限情形验证或找出反例。

### 形式化表述

mesh pattern 等分布：对可分置换类 Sep_N，统计量 p 与 q 满足 |{π∈Sep_N: occ(p,π)=k}| = |{...: occ(q,π)=k}| 对所有k。已知：38类中24类显式确定（原文）。

## 原文摘录

> "Computer experiments suggest that at most 124 pairs of mesh patterns of type {12,21} with identical shading are equidistributed. Using symmetry operations, we partition these pairs into 38 equivalence classes... explicitly determining 24 of these distributions... we reduce the number of equivalences..." (arXiv:2610.08865)
> （出处: Gao, Kitaev, Li, Li, arXiv:2610.08865, 2026-10-05）
>
> —— arXiv 预印本

## 已知结果与进展

原文(2026-10)：24/38类确定+严格不动点类联合分布。

## 边界与约定

- 最小参数/退化: 模式长度≤2 限定（长度1的6类已全部确定）；"identical shading"条件为配对前提。
- 分支/等号: occ=0（k=0）分支对短模式平凡；自反（不动点）类联合分布原文已处理；31类中7类为剩余目标。
- 独立验证建议（与查新途径不同源）: 独立写枚举程序（可分置换生成规范+模式计数）复算 124 对等分布判定与 31 类划分；与原文附录（若有）交叉验证，防计算性断言单源依赖。
