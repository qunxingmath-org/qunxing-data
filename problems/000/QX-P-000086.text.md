# Wilf 数值半群猜想（e|L|≥c）

## 题面

每个数值半群满足 e·|L| ≥ c（e=嵌入维数，L=低于 conductor c 的半群元素数）（Wilf 1978 提问）。

### 形式化表述

e|L| ≥ c 对一切数值半群。

## 原文摘录

> Every numerical semigroup with conductor c, embedding dimension e, and L the semigroup elements below c satisfies e|L|≥c.
>
> —— bespokelabsai/conjecture-bench 策展库 cb-0114（集合: legacy-15-inventory-without-forecasts）
