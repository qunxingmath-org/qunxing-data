# 燃烧数猜想：b(G) ≤ ⌈√n⌉

## 题面

每个 n 点连通图可在 ⌈√n⌉ 步内'燃烧'完（每步引燃一点+已燃点扩散一圈）。

### 形式化表述

∀连通 G, |V|=n: b(G) ≤ ⌈√n⌉。

## 原文摘录

> Burning number conjecture (Bonato–Janssen–Wang 2009): every connected n-vertex graph has burning number b(G) ≤ ⌈√n⌉.
>
> —— 提出: Bonato–Janssen–Wang (2009)
登记: conjecture-bench cb-0164; arXiv:2509.03144; FC 同主题

## 已知结果与进展

路径/特定族已证；一般上界 1.372√n+O(1) 型；2026 结构方法系列（arXiv:2606.02 等）。

## 边界与约定

- 边界：每步一点被点燃+已燃扩散距离1；连通图。
- 独立验证建议：n≤30穷举/ILP算最大b(G)对照√n。
