# Erdős P556：R_3(C_n) ≤ 4n−3（对一切 n≥4）

## 题面

对每个 n≥4，三色圈 Ramsey 数满足 R₃(C_n) ≤ 4n−3。

### 形式化表述

R₃(C_n) ≤ 4n−3 对一切 n≥4（n=3 时字面为假，R₃(C₃)=17）。
