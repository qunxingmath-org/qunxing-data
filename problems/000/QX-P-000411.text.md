# Lipschitz 图无 3 项等差（Green 问题 15）

## 题面

是否存在 Lipschitz 函数 f:ℕ→ℤ，其图像不含非平凡 3 项等差数列？

### 形式化表述

∃f Lipschitz（|f(n+1)−f(n)|≤C）: Γ_f 中无 x+2y=3z 型非平凡解。

## 原文摘录

> Does there exist a Lipschitz function f: ℕ→ℤ whose graph Γ⊂ℤ² contains no nontrivial 3-term arithmetic progression?
>
> —— Ben Green, '100 open problems'（arXiv 讲义，2024；清单 2025-12 更新版仍列 open）

## 已知结果与进展

- Shoal 追踪 2026-10-20 仍标 open（依 Green 清单）；
- [DISPUTED] Liam Kruer 在线声称构造（liamkruer.com, green-15/proof）——未获社区验证，可作为首个核查目标。

## 边界与约定

- 边界：Lipschitz常数C任意（存在性问句）；ℕ域。
- 独立验证建议：Kruer构造程序化验证（有限段模拟+3AP搜索）。
