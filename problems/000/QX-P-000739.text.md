# Erdős #982：凸多边形顶点距离数 ≥⌊n/2⌋

## 题面

凸 n 边形的某顶点到其余顶点至少有 ⌊n/2⌋ 个不同距离（Erdős #982）。

### 形式化表述

凸位置 n 点集 ⇒ max_v d_dist(v) ≥ ⌊n/2⌋。

## 已知结果与进展

- erdosproblems.com/982（fetch 2026-11-20）：开放；下界记录 (13/36+1/22701)n−O(1)（Nivasch–Pach–Pinchasi–Zerbib 2013）；Moser ⌈n/3⌉ 起
- arXiv：1207.1266（2012 凸多边形顶点相异距离数）为部分结果
- CB 反例目标（finite=true）: A rational strictly convex n-gon in which every vertex determines fewer than floor(n/2) distinct distances.
- 族/风险注记: 与排除清单 B17（一般相异距离）同族不同命题，已注记；更强 Erdős 曲线版被 Bárány–Roldán-Pensado 否定——注记区分
