# 大直线或大团（原批次 A-079）

## 题面

对所有参数 (l,c)，是否存在 N(l,c) 使任意 ≥N(l,c) 的平面点集包含 l 个共线点或 c 个两两互视的点？

### 形式化表述

∀l,c∈N ∃N: ∀P（|P|≥N 一般位置平面点集），P 含 l 共线或 visibility-graph 团 K_c。

## 人话版

**一句话**：点够多以后，总能找到很多共线点，或者一大群彼此可见的点吗？

给定平面上的一批点，把两点连起来：若这段线段上不含第三个点，就算它们互相可见，所有可见关系拼成一个可见性图。猜想问：对每对参数 (l,c) 是否存在门限 N(l,c)，使得只要点数不少于 N(l,c)，点集就必然含有 l 个共线点，或者含有 c 个两两可见的点（即可见性图里有 c 个点的团）。这是把 Ramsey 思想搬到几何上：要公要么同线、要么互见。（歧义：题卡写“一般位置点集”，但一般位置通常排除三点共线，与“含 l 个共线点”这一支冲突，条件宜按无三点共线假设去掉来理解。）

（AI 起草，未经人工审校）

## 原文摘录

> (OPG, Kára–Pór–Wood 2005) For all (l,c) does there exist N(l,c): 任意 ≥N 点的平面点集（按可视性）包含 l 共线点或 c 个两两可视点？
>
> —— OPG 页

## 已知结果与进展

- Kára–Pór–Wood (2005)；Addario-Berry 等 (2007)；Abel 等 (2011) 部分情形（采集记录）。
- 2026-08-19 arXiv "Large Finite Point Sets Have 4 Collinear Points or a 6-Clique"；2026-09-22 "…4 Collinear Points or Almost 7-Cliques…"——(4,6) 附近推进。

## 边界与约定

- 边界：一般位置说明（原文'no three collinear'与否需核——可视性图允许遮挡）。
- 独立验证建议：候选N(l,c)以枚举+SAT验证小范围紧性。
