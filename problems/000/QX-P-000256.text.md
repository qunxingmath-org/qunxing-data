# Eisenbud–Green–Harris 猜想（Hilbert 函数支配）

## 题面

若齐次理想含度数为 d1≤…≤dc 的正则列，则其 Hilbert 函数被'前 c 个变量上度数 di 的 lex 理想'支配。

### 形式化表述

∀齐次理想 I⊇(f1..fc) 正则列 deg fi=di: HF_I ≤ HF_{Lex(d1..dc)}（限制前 c 变量）。

## 原文摘录

> EGH conjecture: if a homogeneous ideal contains a regular sequence of degrees d1≤...≤dc, then its Hilbert function is bounded by the lex ideal in the first c variables of those degrees.
>
> —— 提出: Eisenbud–Green–Harris (1996, AMS Bull.)
形式化: formal-conjectures Paper/EisenbudGreenHarris.lean

## 已知结果与进展

二次情形六变量已证（2026）；fast-growing 度序列情形（2007.15467）已证；一般开放。

## 边界与约定

- 边界：正则列度数排序；'前c变量'归约约定（FC限制到子环）。
- 独立验证建议：小c小度数实例Macaulay2计算HF对照lex理想。
