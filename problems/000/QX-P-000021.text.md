# Erdos P156: maximal Sidon set of size O(N^{1/3})

## 题面

是否存在尺寸O(N^{1/3})的极大Sidon集？

### 形式化表述

∃ maximal Sidon A⊂[1,N] with |A|≤C·N^{1/3}. (贪心构造≥c·N^{1/3}; Ruzsa 1998: ≪(N log N)^{1/3}。)
（核对修正注记 2026-11-21，SOL验证Agent：两点约定澄清——①"maximal"=极大（不可再添点），非"maximum"（最大），本命题问的是极小极大值问题；②原文 O(N^{1/3}) 的 N 量词隐含"对每个（充分大）N 都存在且 C 为绝对常数"（若按"存在无穷多 N"读法则命题实质更弱），钉死时须以 EP 页/DeepMind 形式化为准。其余表述与原文一致。）

## 已知结果与进展

- [PARTIAL] Ruzsa (1998): 极大Sidon集 ≪(N log N)^{1/3}。
- [BACKGROUND] 贪心构造下界 ≫N^{1/3}。

## 边界与约定

- 最小参数: 小 N 的极小极大尺寸序列（OEIS A382397）——N≤40 可回溯枚举全部极大 Sidon 集并取最小尺寸，检验其是否 ~N^{1/3}。
- 退化情形: N=1（A={1} 极大，尺寸 1 vs N^{1/3}=1——基线锚点）；maximal≠maximum（极大集可以很小也可以是最大集——命题只关心最小可达的极大集）；C 的绝对性（声称构造须给出显式常数）。
- 约定依赖: Sidon=B₂ 定义；极大性验证=每个未入选点加入都破坏 Sidon 性。
- 结构性锚点: 贪心 ≥c·N^{1/3} 与 Ruzsa ≤C(N log N)^{1/3} 的 log 缺口；Ruzsa 构造（模 p 乘法群结构）是明确起点——声称改进须给出显式构造并机器验证极大性与尺寸。
- 建议独立验证方法（仅描述，不执行）: N≤40 全枚举极小极大尺寸（回溯/ILP，与贪心/Ruzsa 途径不同源）；对声称构造做极大性逐点验证与尺寸渐近拟合。
