# Aharoni–Berger 彩虹匹配猜想（n 个匹配各 n+1 → 彩虹匹配 n）

## 题面

二部多重图中 n 个大小为 n+1的两两不交匹配族必有 n 条彩虹匹配（每色选一边两两不共端点）。

### 形式化表述

n matchings of size n+1 ⇒ rainbow matching of size n。

## 原文摘录

> Every family of n matchings of size n+1 in a bipartite multigraph has a rainbow matching of size n.
>
> —— bespokelabsai/conjecture-bench 策展库 cb-0174（集合: famous-finite-expansion）

## 边界与约定

- 边界：二部多重图；rainbow=每色一边互不共端。
- 独立验证建议：n≤8穷举反例搜索（Drisko线n=2n−1已知）。
