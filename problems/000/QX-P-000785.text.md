# Erdős P1041：多项式亚水平集内根间短路径（长度<2）

## 题面

设 f 为首一多项式且所有根都在开单位圆盘内，则 |f(z)|<1 的亚水平集中，存在连接某两个根（或 0 到单位圆）的路径长度 < 2（CB 陈述版：两根之间路径长 <2）。

### 形式化表述

∀ monic f（根在 𝔻）: lemniscate {z: |f(z)|<1} 内存在连接两根的路径长度 <2。
