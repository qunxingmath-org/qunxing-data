# 批次一的承诺

批次一是群星第一次大规模解题。为了证明题目不是挑出来的，抽题前后分三次把关键文件的哈希合并进这个公开仓库。合并时间由 GitHub 记录，就是时间戳。规则见协作仓库的《批次一抽题方案》第 5、8 节；方案和脚本在论文发表时公开，可以用这里的哈希核对。

| 文件 | 什么时候提交 | 内容 |
|---|---|---|
| `1-rules.json` | 现在，抽题规则定稿时 | 抽题方案和抽题脚本的 sha256 |
| `2-snapshot.json` | 查新结果导入、查重做完以后 | 要抽的 `qunxing-data` 提交号，以及取值表的 sha256 |
| `3-run-order.json` | 抽题以后、开第一道题之前 | 种子、drand 轮次号，以及 `run_order` 的 sha256 |

**种子**：drand 主网 default 链在 max(T1 + 24 小时, T2 + 10 分钟) 之后的第一轮。T1、T2 分别是前两个文件合并进 main 的时间。`seed = sha256("qunxing.batch-1|" + randomness)`。
